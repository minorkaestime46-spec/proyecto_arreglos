# sistema_calificaciones.py
sistema de calificaciones proyectp

## Descripción
Programa desarrollado en Python para administrar
las calificaciones de cinco estudiantes.

## Objetivo
Aplicar los conocimientos sobre arreglos, índices,
ciclos, condiciones y operaciones matemáticas.

## Lenguaje utilizado
Python 3.

## Funcionalidades
- Mostrar las calificaciones.
- Consultar una nota mediante su índice.
- Calcular el promedio general.
- Encontrar la nota mayor y la menor.
- Contar estudiantes aprobados y reprobados.
- Modificar una calificación.
- Mostrar el vector actualizado.

## Instrucciones para ejecutar
1. Instalar Python 3 o utilizar un entorno en línea.
2. Abrir el archivo sistema_calificaciones.py.
3. Ejecutar el programa.
4. Seguir las instrucciones en pantalla.
